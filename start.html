Что пока не добавлено

Итоговые контрольные ещё не опубликованы. Темы, обязательные формулы, перечень лабораторных и требования сверяют с учителем. Домашний аналог не считается автоматически школьной лабораторной.

Как заниматься

  1. Прочитай небольшой фрагмент объяснения.
  2. Рассмотри рисунок и объясни его смысл.
  3. Пройди по шагам схемы.
  4. Попробуй задачу; при затруднении открой подсказку.
  5. Объясни ответ своими словами.

Дополнительные расчёты можно отложить. Для лабораторных не выдумывай измерения.

Сохранение результатов

Каждый раздел хранит данные отдельно в этом браузере. Меню ничего не сбрасывает. Очистка данных может удалить результаты. Для лабораторных доступны выгрузка отчёта и резервная копия всех черновиков; автоматической синхронизации между устройствами нет.
